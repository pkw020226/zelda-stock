# 젤다 40주년 프로콘 재고판

Cloudflare Workers + Static Assets 배포용입니다. 서버 업로드 직전 상태로 구성했습니다.

## 기능
- 확보한 13개 개별 상품 URL을 서버에서 직접 조회
- 검색결과/장바구니/구매버튼만으로 재고 판정하지 않는 보수적 규칙
- 품절 신호가 하나라도 있으면 품절 우선
- 명시적 `재고 N개`, `잔여 수량 N`, `구매 가능`, `주문 가능` 등만 구매 가능 판정
- HTTP 차단/동적 렌더링/검증 불가는 `확인 불가`
- 웹 UI에서 전체/개별 재확인, 2분 자동 새로고침
- 서버 cron은 5분 간격으로 체크(Cloudflare 플랜의 cron 실행 제약은 계정 설정에 따름)

## 배포 직전 명령
1. Node.js 설치
2. 이 폴더에서 `npm install`
3. `npx wrangler login`
4. 로컬 확인: `npm run dev`
5. 배포: `npm run deploy`

배포 후 `https://zelda40-stock-watch.<계정>.workers.dev` 형태의 주소가 생성됩니다.

## 중요한 한계
쇼핑몰마다 Cloudflare 서버 요청을 차단하거나, 재고 상태를 JavaScript/API 호출 뒤에만 렌더링할 수 있습니다. 이런 경우 이 사이트는 거짓 양성(재고 있음)을 만들지 않고 `확인 불가`로 표시합니다. 브라우저 자동화/사이트별 API 분석을 추가하면 확인 가능한 판매처를 늘릴 수 있습니다.
